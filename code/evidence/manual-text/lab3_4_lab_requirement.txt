实验报告要求
基于
markdown
格式完成实验报告，以文本说明为主。
说明自己对本章节整体逻辑线的理解，即本章节是按照什么顺序、围绕哪些功能逐步实现的。
说明自己对每个功能的核心函数或功能模块的理解。
说明每个练习的
spec
是怎么写的，
prompt
是怎么写的。
说明在使用提示词让 AI 生成代码的过程中出现了什么 bug，以及你是怎么解决的。
列出你认为本实验中重要的知识点，以及与对应 OS 原理中的知识点，并简要说明二者的含义、关系和差异。
列出你认为 OS 原理中很重要、但在本实验中没有对应上的知识点。
从 oslab 网站上取得实验代码后，进入目录
labcodes/lab3
，完成实验要求的各个练习。在目录
labcodes/lab3
下存放实验报告，推荐使用
markdown
格式。每个小组建立一个 gitee 或 github 仓库，对于 lab3 中的编程任务，完成编写之后，再通过
git push
命令把代码和报告上传到仓库，最后请提前或按时提交到 git 网站。
注意有“lab3”的注释，代码中所有需要完成的地方（challenge 除外）都有“lab3”和“YOUR CODE”的注释，请在提交时特别注意保持注释，并将“YOUR CODE”替换为自己的学号，并把所有标有对应注释的部分填上正确的代码。
